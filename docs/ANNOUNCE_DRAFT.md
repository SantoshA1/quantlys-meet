I open-sourced Quantlys Meeting.

I’m Santosh Adari. I built this as dogfood for Quantlys (https://www.quantlys.ai) — an AI vertical platform I work on. We run the live product at quantlys-meeting.com. The GitHub repo is the meeting app itself, MIT-licensed, so other builders can plug their own keys and run a white-label video stack.

What it does:

• Browser video meetings (LiveKit) with guests joining from a link  
• Live captions via Deepgram; auth/history via Supabase; recordings to S3-compatible storage  
• After the session: markdown PRD / notes from the recording (your OpenAI or OpenRouter key) — for product work that happens in the call  
• Memory mode — a second surface for podcasts (chapters/clips), books, and oral history / legacy stories  

Bring your own LiveKit, Deepgram, Supabase, model key, and object storage. Clone, fill `.env.example`, run. Deploy path on Vercel is documented; self-hosted SFU notes are in the repo.

Quantlys Conclave and the rest of the platform stay closed. Meeting ships Conclave-compatible PRD rubrics and honest paste-handoff — not a one-click Conclave API. No invented customer claims; this is my dogfood product, open for builders.

Repo / release: https://github.com/SantoshA1/quantlys-meet/releases/tag/v1.0.0-oss  

If you build meeting tools, podcast pipelines, or self-hosted AI apps — I’d love a star, a fork, or an issue. Happy to answer questions in the comments.
